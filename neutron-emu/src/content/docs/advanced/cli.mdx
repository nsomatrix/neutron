## Usage

Neutron is launched as a packaged Java Archive (JAR) executable. Run the emulator by executing the JAR file with the Java Runtime Environment (JRE):

```bash
java -jar neutron.jar [options] [midlet-class | jar-path | jad-path]
```

You can target a specific MIDlet class, a compiled game `.jar` file, or a `.jad` descriptor file.

## Options Reference

The following parameters are supported by the CLI launcher:

### Basic Options

| Option | Parameters | Description |
|--------|------------|-------------|
| `--help`, `-help` | None | Prints the command-line usage manual and exits. |
| `--id` | `[EmulatorID]` | Redefines the emulator environment workspace/home path to `~/.neutron/[EmulatorID]/`. Use this to run multiple independent profiles concurrently. |
| `--quit` | None | Automatically shuts down and exits the JVM when the active MIDlet is destroyed. |
| `--headless` | None | Runs the emulator in headless mode (no GUI displays). |
| `--quiet` | None | Suppresses standard terminal output logging messages. |

### Device & Display Configuration

| Option | Parameters | Description |
|--------|------------|-------------|
| `-d`, `--device` | `[descriptor | class]` | Selects a specific device profile descriptor XML or custom device implementation class. |
| `--resizableDevice` | `[width] [height]` | Starts the emulator using a resizable device interface set to the specified virtual screen dimensions (e.g. `240 320`). |

### Storage & Resources

| Option | Parameters | Description |
|--------|------------|-------------|
| `--rms` | `file` or `memory` | Configures the Record Store Management system backend. Stores data to disk (`file`) or volatile RAM (`memory`). |
| `--propertiesjad` | `[jad path]` | Supplies an external `.jad` configuration file when launching a raw MIDlet class. |
| `-cp`, `--classpath` | `[classpath]` | Adds custom paths or JAR files to the JSR extension classloader path. |
| `--appcp`, `--appclasspath` | `[classpath]` | Adds paths to search for user-defined MIDlet classes. |

### Diagnostics & Testing

| Option | Parameters | Description |
|--------|------------|-------------|
| `-Xautotest:` | `[jad-url]` | Initiates automated headless test suite execution for the specified JAD. |
| `--logCallLocation` | `true` or `false` | Includes Java class call locations inside the console log outputs. |
| `--traceClassLoading` | None | Enables tracing of MIDlet classloading in the console. |
| `--traceSystemClassLoading` | None | Enables tracing of system classloader requests. |
| `--enhanceCatchBlock` | None | Enables diagnostic bytecode verification processing on catch blocks. |

## Examples

### Running a game with a custom screen resolution:
```bash
java -jar neutron.jar --resizableDevice 240 320 mygame.jar
```

### Running with a custom profile ID (e.g. for split-screen testing):
```bash
java -jar neutron.jar --id Profile2 player2.jar
```

### Headless execution with memory-based RMS:
```bash
java -jar neutron.jar --headless --rms memory --quit testsuite.jar
```
