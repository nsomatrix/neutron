## Plugin System

Neutron features a modular plugin architecture that allows you to extend its functionality without modifying the core codebase.

## Installing Plugins

Place plugin JAR files in the plugins directory:

| Platform | Path |
|----------|------|
| Windows | `%APPDATA%\Neutron\plugins\` |
| macOS | `~/Library/Application Support/Neutron/plugins/` |
| Linux | `~/.config/neutron/plugins/` |

Plugins are loaded automatically on startup.

## Creating a Plugin

### Plugin Interface

```java
public interface NeutronPlugin {
    String getName();
    String getVersion();
    void onLoad(PluginContext ctx);
    void onUnload();
}
```

### Example Plugin

```java
public class MyPlugin implements NeutronPlugin {
    @Override
    public String getName() { return "MyPlugin"; }

    @Override
    public String getVersion() { return "1.0.0"; }

    @Override
    public void onLoad(PluginContext ctx) {
        ctx.registerCommand("hello", args -> {
            System.out.println("Hello from MyPlugin!");
        });
    }

    @Override
    public void onUnload() {
        // Cleanup resources
    }
}
```

### Plugin Context

The `PluginContext` provides access to Neutron's internal APIs:

| Method | Description |
|--------|-------------|
| `registerCommand()` | Add a CLI command |
| `getEmulator()` | Access the emulator instance |
| `getConfig()` | Read configuration |
| `getLogger()` | Get a scoped logger |

## Plugin Lifecycle

1. **Discovery** — JARs in the plugins directory are scanned
2. **Loading** — `onLoad()` is called with a context
3. **Active** — Plugin runs alongside the emulator
4. **Unloading** — `onUnload()` is called on shutdown

<Callout type="warning">
Plugins have full access to the Java runtime. Only install plugins from trusted sources.
</Callout>
