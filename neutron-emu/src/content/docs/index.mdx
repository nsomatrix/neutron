## What is Neutron?

Neutron is a fast, accurate, and lightweight Java ME (Micro Edition) emulator that lets you run MIDP 2.0 and CLDC 1.1 applications on modern desktop platforms. Whether you're a developer testing legacy applications or a retro gaming enthusiast revisiting classic mobile games, Neutron provides the tools you need.

## Key Features

- **High Performance** — Optimized runtime with JIT-style compilation for near-native execution speed
- **Accurate Emulation** — Full MIDP 2.0 and CLDC 1.1 specification compliance
- **Cross Platform** — Runs on Windows, macOS, and Linux
- **Modern UI** — Clean, themeable interface with dark mode support
- **Developer Tools** — Built-in debugging, profiling, and CLI support
- **Plugin System** — Extensible architecture for custom functionality
- **Open Source** — Free and open source under the LGPL license

## System Requirements

Neutron runs on any system with Java 11 or later. For optimal performance, we recommend:

- **OS**: Windows 10+, macOS 11+, or Ubuntu 20.04+
- **RAM**: 256 MB minimum, 512 MB recommended
- **Disk**: 50 MB for the application
- **Java**: JDK 11 or later (JDK 17+ recommended)
