## What is Neutron?

**Neutron** is a fast, accurate, and lightweight Java ME (Micro Edition) emulator designed to run classic MIDP/CLDC applications and mobile games on modern desktop platforms (Windows, macOS, and Linux).

Originally born to modernize mobile Java preservation, Neutron combines direct host JVM execution speeds with a contemporary FlatLaf desktop interface, extensive mobile 3D engine support (MascotCapsule Micro3D v3 and JSR-184 M3G), high-definition pixel-art shaders (xBRZ), and comprehensive developer diagnostics.

---

## Key Highlights

- **Native Execution Performance** — Runs MIDlets directly on modern Java Virtual Machines with zero CPU emulation overhead.
- **CLDC 1.1 & MIDP 2.0 Compliance** — Full LCDUI user interface components, Game API canvas rendering, and RMS database persistence.
- **3D Graphics Support** — Built-in pure-Java software rasterizers for **MascotCapsule Micro3D v3** and **JSR-184 (M3G)**.
- **High-Definition Scalers** — Crisp **xBRZ (up to 6x)**, Scale2x, retro **CRT scanlines**, and handheld **LCD subpixel grids**.
- **Interactive Virtual Keypad (`Ctrl+B`)** — On-screen 8-way directional pad, diagonals, softkeys, and 12-key numeric keyboard for touchscreens and mice.
- **Audio Subsystem** — Comprehensive MMAPI support for WAV, Sun AU, AMR voice, Java Sound MIDI synthesizer, and tone sequences.
- **Developer Diagnostics** — Performance HUD (live FPS & frame timings), Log Console, GCF Network Capture, and RMS Record Store Manager.
- **Open Source** — Dual-licensed under the **GNU LGPL v2.1** and **Apache License 2.0**.

## System Requirements

- **Operating System:** Windows 10/11, macOS 11+ (Big Sur or newer), or modern Linux distributions (Ubuntu, Fedora, Arch).
- **Runtime:** Java Runtime Environment (JRE) or Java Development Kit (JDK) 8 or later (**Java 17+ / 21+ LTS recommended**).
- **Memory Footprint:** Less than 50 MB RAM for the core emulator; starts up in milliseconds.
