This guide provides step-by-step instructions on compiling, testing, and packaging the complete Neutron emulator suite from source.

---

## Prerequisites

To build Neutron, your development workstation needs:

### 1. Java Development Kit (JDK 17+)
A standard Java Development Kit (JDK) 17 or higher with `javac` and jar packaging tools:
- **Recommended Distribution:** [Eclipse Temurin OpenJDK 17 or 21](https://adoptium.net/)
- Verify your environment:
  ```bash
  java -version
  javac -version
  ```

### 2. Audio Library Headers (Linux only)
If building on Linux, install ALSA development headers for digital audio mapping:
```bash
# Ubuntu / Debian
sudo apt update && sudo apt install libasound2-dev

# Fedora / RHEL
sudo dnf install alsa-lib-devel

# Arch Linux
sudo pacman -S alsa-lib
```
*(Windows and macOS bundle native audio libraries automatically with the JDK.)*

### 3. Gradle Wrapper
The repository includes the Gradle wrapper (`./gradlew` and `gradlew.bat`). No separate Gradle installation is needed.

## Clone the Repository

```bash
git clone https://github.com/nsomatrix/neutron.git
cd neutron
```

---

## Build Targets

Neutron uses a multi-project Gradle layout. All commands should be run from the repository root:

### 1. Compile & Assemble Release Binaries
To compile all modules and build both the Full Swing edition and the compressed Core edition:
```bash
./gradlew jar
```

Generated JAR files:
- **Neutron Express (Full Swing Desktop):**
  `neutron/neutron-javase-swing/build/libs/neutron-javase-swing-1.4.0.jar`
- **Neutron Core (Compressed Payload Launcher):**
  `neutron/neutron-core/build/libs/neutron-core-1.4.0.jar`

### 2. Running Full Tests
Execute unit tests across all CLDC, MIDP, M3G, and extension modules:
```bash
./gradlew test
```

### 3. Fast Build (Skip Tests)
```bash
./gradlew build -x test
```

### 4. Cleaning the Build
```bash
./gradlew clean
```

---

## Running the Compiled Binaries

### Run via Gradle Task
The root project includes an orchestrated `run` task that builds and launches both the Full desktop and Core versions:
```bash
./gradlew run
```

Or run the Swing application directly with custom arguments:
```bash
./gradlew :neutron:neutron-javase-swing:run --args="mygame.jar"
```

### Run via Java Directly
```bash
# Run Full Desktop Edition
java -jar neutron/neutron-javase-swing/build/libs/neutron-javase-swing-1.4.0.jar

# Run Minimal Core Edition
java -jar neutron/neutron-core/build/libs/neutron-core-1.4.0.jar
```

## Building the Web Hub (`neutron-emu`)

The modern web portal and documentation engine are powered by Next.js and Tailwind CSS located in `neutron-emu/`:

```bash
cd neutron-emu
npm install
npm run dev
```

To create a static production build:
```bash
npm run build
```
