## Network Overview

Neutron implements the Java ME **Generic Connection Framework (GCF)** located in `javax.microedition.io.*`. It bridges mobile network requests directly to host Java SE network sockets, supporting HTTP, HTTPS, TCP streaming sockets, and UDP datagrams.

---

## Supported GCF Protocols

| Connection URL | Interface | Underlying Implementation |
|----------------|-----------|---------------------------|
| `http://...` | `HttpConnection` | Full HTTP 1.1 request/response handling. |
| `https://...` | `HttpsConnection` | SSL/TLS encrypted traffic using host truststores. |
| `socket://host:port` | `SocketConnection` | Direct TCP streaming socket. |
| `serversocket://:port`| `ServerSocketConnection` | Bound listening TCP server socket. |
| `datagram://host:port`| `UDPDatagramConnection` | UDP datagram sending and receiving. |
| `sms://...` | `MessageConnection` (JSR-120) | Emulated wireless messaging connection. |

### Strict HTTP GET / POST Handling

In Neutron v1.4.0, HTTP connections strictly maintain the default `GET` request method unless `conn.setRequestMethod(HttpConnection.POST)` or an explicit `openOutputStream()` is invoked, matching physical phone specifications.

```java
// Example HTTP Connection in MIDlet code
HttpConnection conn = (HttpConnection) Connector.open("http://example.com/api/highscore");
conn.setRequestMethod(HttpConnection.GET);

int responseCode = conn.getResponseCode();
if (responseCode == HttpConnection.HTTP_OK) {
    InputStream is = conn.openInputStream();
    // Read response payload...
    is.close();
}
conn.close();
```

## Network Controls & Diagnostics

Neutron provides dedicated tools in the **Controls** menu for monitoring and regulating network traffic:

### 1. Airplane Mode
Quickly toggle all network communication on or off. When enabled in **Controls → Airplane Mode**, outbound socket and HTTP connections are temporarily blocked, enabling you to test how games handle network dropouts without killing the emulator.

### 2. X-Proxy Settings
Route all GCF network activity through an HTTP or SOCKS proxy:
- Open **Controls → X-Proxy**.
- Configure Proxy Type (`HTTP` or `SOCKS`), Host IP/Domain, and Port.
- Enable Proxy Authentication if your proxy server requires credentials.
- Settings are automatically persisted under `<options>` in `config2.xml`.

### 3. Network Traffic Overlay
Toggle **Controls → Network Overlay** to display a real-time HUD showing:
- Active open network connections.
- Data throughput (bytes sent / received).
- Live latency and ping counters.

### 4. Packet Capture Dialog
Open **Controls → Network Capture** to inspect raw HTTP requests, response headers, and socket communication payloads in real time.
