## Storage Overview

Neutron provides two distinct persistent storage mechanisms for Java ME applications:
1. **Record Management System (RMS):** Standard MIDP record-based database for save games, user preferences, and high scores.
2. **FileConnection API (JSR-75):** Access to local filesystem storage, virtual memory cards, and documents.

---

## Record Management System (RMS)

RMS stores discrete binary records indexed by ID within named record stores.

```java
import javax.microedition.rms.*;

// Open or create a record store named 'SaveData'
RecordStore rs = RecordStore.openRecordStore("SaveData", true);

byte[] gameScore = "99990".getBytes("UTF-8");
int recordId = rs.addRecord(gameScore, 0, gameScore.length);

// Read back the saved score
byte[] retrieved = rs.getRecord(recordId);
String score = new String(retrieved, "UTF-8");

rs.closeRecordStore();
```

### Storage Location on Disk

By default, Neutron uses `FileRecordStoreManager` to serialize RMS databases into individual `.rms` files on your host drive:

| Platform | RMS Root Directory Path |
|----------|-------------------------|
| **Windows** | `%USERPROFILE%\.neutron\suite-[MIDletName]\` |
| **macOS** | `~/.neutron/suite-[MIDletName]/` |
| **Linux** | `~/.neutron/suite-[MIDletName]/` |

If launched with a custom profile ID (`--id [ProfileID]`), the path becomes `~/.neutron/[ProfileID]/suite-[MIDletName]/`.

<Callout type="tip">
You can also run Neutron with pure in-memory RMS storage using the CLI flag: `--rms memory`. In memory mode, no files are written to disk, and state resets when the application closes.
</Callout>

### RMS Inspector Dialog

Neutron includes a built-in GUI inspector to manage saved data:
1. Open **Config → Record Store Manager**.
2. Select any active or previous MIDlet suite.
3. Inspect record IDs, byte lengths, and raw hex/string contents.
4. Modify, import, or delete corrupted records with a single click.

## FileConnection (JSR-75)

Neutron fully implements the **JSR-75 FileConnection** specification (`javax.microedition.io.file.*`):

- **Virtual Root Drives:** Emulates root file structures like `root/`, `memory_card/`, and `c:/`.
- **Security & Integrity:** In v1.4.0, strict read-only mode checks (`Connector.READ`) are enforced throwing `IllegalModeException` on illegal write attempts.
- **Path Traversal Protection:** Relative path escapes (`../`) outside the isolated virtual root boundaries are blocked to prevent accidental host system modification.

## Snapshot Manager (Backup & Restore)

Neutron includes a built-in state preservation system:
- **Backup:** Go to **Run → Snapshot → Backup** to export your entire configuration, RMS save files, and preferences into a single compressed `.zip` archive.
- **Restore:** Go to **Run → Snapshot → Restore** to load a previously exported backup archive onto any other machine.
