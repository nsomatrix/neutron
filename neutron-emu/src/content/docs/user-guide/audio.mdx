## Audio Architecture Overview

Neutron emulates the Java ME Mobile Media API (MMAPI / JSR-135) through native Java Sound synthesizers and audio players. It supports multi-channel audio mixing, non-destructive looping, dynamic volume adjustments, and programmatic tone synthesis.

---

## Supported Formats

| Audio Format | MIME Type / File Extension | Implementation Engine | Typical Usage |
|--------------|----------------------------|-----------------------|---------------|
| **WAV (PCM)** | `audio/x-wav`, `.wav` | `SampledAudioPlayer` / Java Sound PCM | Sound effects, dialogue, ambient audio. |
| **AU (Sun Audio)** | `audio/basic`, `.au` | `SampledAudioPlayer` | Vintage sampled audio clips. |
| **AMR (Adaptive Multi-Rate)** | `audio/amr`, `.amr` | `AmrAudioPlayer` | Mobile narrowband voice clips and ringtones. |
| **MIDI** | `audio/midi`, `.mid`, `.midi` | Java Sound `MidiSystem` Sequencer | Polyphonic background music tracks. |
| **Tone Sequences** | `audio/x-tone-seq`, programmatic | `TonePlayer` / Audio Synthesizer | Retro chiptune beeps, alerts, and ringtones. |

## MMAPI Usage Examples

### 1. Playing Sampled Audio (WAV / AMR)

```java
import javax.microedition.media.*;
import javax.microedition.media.control.VolumeControl;
import java.io.InputStream;

InputStream is = getClass().getResourceAsStream("/sfx/explosion.wav");
Player player = Manager.createPlayer(is, "audio/x-wav");

// Realize and allocate system resources
player.realize();
player.prefetch();

// Adjust volume
VolumeControl vc = (VolumeControl) player.getControl("VolumeControl");
if (vc != null) {
    vc.setLevel(85); // Range: 0 to 100
}

// Start playback
player.start();
```

### 2. Looping MIDI Background Music

Neutron supports non-destructive loop count semantics (`player.setLoopCount(-1)` for infinite looping):

```java
InputStream midiStream = getClass().getResourceAsStream("/music/theme.mid");
Player bgmPlayer = Manager.createPlayer(midiStream, "audio/midi");
bgmPlayer.realize();
bgmPlayer.prefetch();
bgmPlayer.setLoopCount(-1); // Seamless continuous repeat
bgmPlayer.start();
```

### 3. Programmatic Tone Synthesis

Trigger hardware frequency tones directly using the MIDP Manager:

```java
// PlayTone(int note, int durationMs, int volume)
// Note 60 is Middle C; duration in milliseconds; volume 0-100
Manager.playTone(60, 250, 100);
```

## Audio Extensions (JSR-234 AMMS)

Neutron includes support for the **Advanced Multimedia Supplements (JSR-234 AMMS)** standard under `javax.microedition.amms.*`:

- **3D Positional Audio:** Spectator orientation and sound source coordinates via `LocationControl` and `OrientationControl`.
- **Audio Effects:** Dynamic equalization and environmental reverberation via `EqualizerControl` and `ReverbControl`.

## Troubleshooting & Audio Configuration

- **Linux Sound Server:** Ensure the ALSA library is installed:
  ```bash
  sudo apt install libasound2
  ```
- **Volume Levels:** Master volume can be adjusted directly from your host operating system mixer or in-game volume settings.
- **Repeat Playback:** In v1.4.0, MMAPI player lifecycles feature automated stream rewinding, eliminating crashes when sound clips are re-triggered rapidly in arcade games.
