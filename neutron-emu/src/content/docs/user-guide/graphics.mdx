## Display Subsystem Overview

Neutron incorporates a graphics pipeline engineered to execute classic 2D LCDUI and intensive 3D mobile games while scaling cleanly onto modern, high-resolution desktop monitors.

---

## 2D Canvas & Game API

Neutron implements the complete MIDP 2.0 Graphics specification:

- **Direct Pixel Access:** Fast software blitting and RGB rasterization.
- **GameCanvas:** Hardware double-buffered canvas supporting asynchronous keyboard states (`getKeyStates()`) and zero-flicker graphics flushing.
- **Sprite & Collision Handling:** Accurate frame-based animations, collision detection (bounding box and pixel-level), and full matrix orientation transforms:
  - `TRANS_NONE`, `TRANS_ROT90`, `TRANS_ROT180`, `TRANS_ROT270`
  - `TRANS_MIRROR`, `TRANS_MIRROR_ROT90`, `TRANS_MIRROR_ROT180`, `TRANS_MIRROR_ROT270`
  - Exact reference pixel coordinate calculations preserving sprite positioning across all rotations.

```java
// Example MIDP 2.0 GameCanvas implementation
public class MyGameCanvas extends GameCanvas implements Runnable {
    public MyGameCanvas() {
        super(true); // Double-buffered
    }

    public void run() {
        Graphics g = getGraphics();
        while (running) {
            int keyStates = getKeyStates();
            if ((keyStates & LEFT_PRESSED) != 0) player.move(-2, 0);
            if ((keyStates & RIGHT_PRESSED) != 0) player.move(2, 0);

            // Paint layers
            layerManager.paint(g, 0, 0);
            flushGraphics();

            try { Thread.sleep(16); } catch (InterruptedException e) {}
        }
    }
}
```

## 3D Graphics Pipelines

Neutron provides dedicated support for mobile 3D game engines:

### 1. MascotCapsule Micro3D v3 (`com.mascotcapsule.micro3d.v3.*`)
A pure-Java software rasterizer implementation supporting:
- 3D Figure model rendering (`.mbac` format)
- Action skeletal animation tables (`.mtac` format)
- Bone transformations and affine matrices (`AffineTrans`)
- Spherical environment mapping and dynamic lighting
- Sub-pixel rasterization with perspective-correct texture mapping

### 2. JSR-184 Mobile 3D Graphics (M3G)
A full implementation of the Java ME standard 3D specification:
- Binary `.m3g` chunk stream parser with Zlib inflation and Adler-32 checksum integrity checks.
- Immediate mode and retained mode scene graphs.
- Scene components: `World`, `Camera`, `Light`, `Background`, `Fog`, `Mesh`, `SkinnedMesh`, `MorphingMesh`, `Appearance`, `Material`, `Texture2D`, `CompositingMode`, and `PolygonMode`.
- Keyframe animation tracks with `AnimationController`.

### 3. Nokia UI DirectGraphics (`com.nokia.mid.ui.*`)
- Extended `DirectGraphics` operations: `drawPixels`, `getPixels`, and `drawPolygon`.
- 32-bit ARGB rasterization supporting custom alpha blends and rotation flags.

## Scaling Filters & Shader Effects

Neutron features a suite of real-time post-processing shaders and scaling algorithms accessible under **Config → Graphics Filter**:

| Filter | Category | Description |
|--------|----------|-------------|
| **Nearest Neighbor** | Raw Pixel | Clean nearest-neighbor scaling preserving sharp square pixels. Fastest execution speed. |
| **xBRZ (2x, 3x, 4x, 5x, 6x)** | HD Pixel-Art | High-definition rule-based edge detection and blending. Smooths curves and diagonals without blurring. |
| **Scale2x** | Pixel Art | Classic EPX / AdvanceMAME algorithm for doubling pixel resolution. |
| **Bilinear / Bicubic** | Interpolation | Smooth mathematical anti-aliased texture filtering. |
| **CRT Scanlines** | Retro Simulation | Simulates horizontal phosphor raster lines of classic CRT monitors. |
| **LCD Grid** | Handheld Simulation | Recreates the authentic physical subpixel matrix grid of retro phone displays. |

## Video Post-Processing Controls

Under **Config → Video Settings**, you can calibrate display output in real-time:

- **Brightness & Contrast:** Adjust dynamic range and shadows.
- **Gamma Correction:** Correct dark gamma curves from vintage color profiles.
- **Saturation:** Reduce to 0% for classic monochrome display emulation or boost for vibrant LCD colors.
- **Sharpness:** High-pass filter for enhanced edge clarity.
- **Phosphor Ghosting:** Emulates the slow liquid crystal response times of early mobile monochrome and CSTN screens.
- **Color Inversion:** Invert screen colors for accessibility or specialized testing.

## Fullscreen & Display Modes

- **Borderless Fullscreen (`F11`):** Completely hides the window border, title bar, and system taskbar. Move your mouse to the top to access the floating menu button.
- **DualZoom Mode:** Doubles canvas scale in a dedicated pop-out viewport.
- **Mouse Coordinates HUD:** Display real-time pointer coordinates directly over the active canvas.
