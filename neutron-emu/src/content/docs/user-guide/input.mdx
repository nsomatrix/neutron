## Input Overview

Neutron translates modern desktop peripherals (keyboards, mice, and touchscreens) into Java ME mobile key events and stylus pointer coordinates.

---

## Desktop Keyboard Controls

### Primary Key Mappings

| Desktop Key | J2ME Button Name | Mobile Equivalent | J2ME Key Code |
|-------------|------------------|-------------------|---------------|
| **F1** | `ButtonName.SOFT1` | Left Soft Key (Menu / Select) | `-6` |
| **F2** | `ButtonName.SOFT2` | Right Soft Key (Back / Exit) | `-7` |
| **Enter** | `ButtonName.SELECT` | FIRE / Action Key | `-5` |
| **Arrow Up (↑)** | `ButtonName.UP` | D-Pad Up | `-1` |
| **Arrow Down (↓)** | `ButtonName.DOWN` | D-Pad Down | `-2` |
| **Arrow Left (←)** | `ButtonName.LEFT` | D-Pad Left | `-3` |
| **Arrow Right (→)** | `ButtonName.RIGHT` | D-Pad Right | `-4` |
| **Backspace** | `ButtonName.BACK_SPACE` | Backspace | `-8` |
| **Delete / Clear** | `ButtonName.DELETE` | Clear / Delete | `-8` |

## On-Screen Virtual Buttons (`Ctrl+B`)

Neutron features an interactive, dynamic on-screen mobile gamepad panel engineered for mouse-driven play and touch-enabled devices (laptops, Steam Deck, tablets):

- **Toggle Shortcut:** Press `Ctrl+B` or click **Config → Virtual Buttons**.
- **Adaptive Layout:** Dynamically adjusts to any canvas size (from 176x220, 240x320 up to 480x800) without compressing the game canvas.
- **Top Control Bar:** Left Soft Key (`Menu`), Close button, and Right Soft Key (`Back`).
- **8-Way Directional Pad:** Supports both cardinal directions (▲ ▼ ◀ ▶) and diagonal presses (↖ ↗ ↙ ↘) for isometric games.
- **Numeric 12-Key Pad:** Includes keys 0–9, \*, and # with intelligent auto-repeat for typing and rapid movement.
- **Form Auto-Paste:** When entering text into LCDUI Form text fields, clicking virtual numeric keys instantly pastes the character into the active field.

## Pointer & Touch Gestures

For touchscreen MIDlets and stylus games:

| Physical Gesture | Emulated Java ME Event |
|------------------|------------------------|
| **Left Click / Tap** | `pointerPressed(int x, int y)` |
| **Click + Drag / Swipe** | `pointerDragged(int x, int y)` |
| **Release Click / Lift** | `pointerReleased(int x, int y)` |

The pointer coordinates are mapped directly to the virtual screen's coordinate matrix, unaffected by integer zoom or window scaling.

<Callout type="tip">
Enable **Config → Mouse Coordinates** to view a live HUD displaying the exact pointer `(X, Y)` position over the game screen.
</Callout>
