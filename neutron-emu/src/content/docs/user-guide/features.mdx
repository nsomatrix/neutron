## Overview

Neutron provides a complete Java ME runtime environment with support for the most commonly used APIs and extensions. This page provides an overview of all major features.

## MIDP 2.0 Support

Full implementation of the Mobile Information Device Profile 2.0 specification:

- **LCDUI** — Complete UI toolkit including Forms, Lists, TextBoxes, Alerts, and Canvas
- **Game API** — GameCanvas, Sprite, TiledLayer, and LayerManager
- **RMS** — Record Management System for persistent data storage
- **Networking** — HTTP, HTTPS, Socket, and Datagram connections
- **Media** — Audio playback via MMAPI (Mobile Media API)
- **Push Registry** — Scheduled and network-triggered MIDlet activation

## CLDC 1.1 Support

Full Connected Limited Device Configuration 1.1 implementation:

- Complete `java.lang`, `java.util`, and `java.io` packages
- Floating-point math support
- Thread management
- Generic Connection Framework (GCF)

## Display Features

- Multiple resolution presets (128×160 to 480×800)
- Integer and smooth scaling
- Fullscreen mode with auto-hide UI
- VSync support
- Custom frame rate limiting
- Screenshot capture

## Audio System

- PCM audio playback (WAV, AU)
- MIDI playback
- Tone generation
- Volume control
- Multiple simultaneous audio streams

## Input System

- Full keyboard mapping for J2ME keys
- Customizable key bindings
- Gamepad / controller support
- Touch simulation via mouse
- Multi-key input (key chording)

## Networking

- HTTP and HTTPS connections
- TCP socket connections
- UDP datagram support
- Proxy configuration (HTTP, SOCKS4, SOCKS5)
- Network activity monitoring
- Global network toggle

## Developer Tools

- Built-in MIDlet inspector
- Memory usage monitoring
- FPS counter
- Logging with configurable levels
- Plugin architecture for extensions
