## Configuration File

Neutron stores its user configuration in an XML file named `config2.xml` located in the user's home directory.

| Platform | Path |
|----------|------|
| Windows | `%USERPROFILE%\.neutron\config2.xml` |
| macOS | `~/.neutron/config2.xml` |
| Linux | `~/.neutron/config2.xml` |

If you specify an instance ID using the `--id [ID]` command-line option, Neutron will store its configuration under `~/.neutron/[ID]/config2.xml`.

## Example Configuration

Here is an example structure of a `config2.xml` file representing user preferences:

```xml title="config2.xml"
<?xml version="1.0" encoding="UTF-8"?>
<config>
  <options>
    <theme>FlatLaf macOS Light</theme>
    <graphicsFilter>Nearest Neighbor</graphicsFilter>
    <fullscreen>false</fullscreen>
    <sleepMode>false</sleepMode>
    <memoryLimit>64</memoryLimit>
    <maxFps>-1</maxFps>
    <speedMultiplier>1.0</speedMultiplier>
    <perfHudEnabled>false</perfHudEnabled>
    <networkAccess>true</networkAccess>
    <networkOverlayEnabled>false</networkOverlayEnabled>
    <showMouseCoordinates>false</showMouseCoordinates>
    <scaledDisplayZoom>-1</scaledDisplayZoom>
    
    <!-- Proxy Settings -->
    <proxyEnabled>false</proxyEnabled>
    <proxyType>HTTP</proxyType> <!-- HTTP or SOCKS -->
    <proxyHost></proxyHost>
    <proxyPort>8080</proxyPort>
    <proxyAuthEnabled>false</proxyAuthEnabled>
    <proxyUsername></proxyUsername>
    <proxyPassword></proxyPassword>
    
    <!-- Video Processing Settings -->
    <brightness>0</brightness>
    <contrast>100</contrast>
    <gamma>1.0</gamma>
    <saturation>100</saturation>
    <sharpness>0</sharpness>
    <ghosting>0</ghosting>
    <invert>false</invert>
  </options>
  <system-properties>
    <system-property name="avetana.forceNativeLibrary" value="true" />
  </system-properties>
</config>
```

## Settings Reference

All settings under the `&lt;options&gt;` tag can be updated through the emulator's GUI menus or edited manually in the XML file while the emulator is closed.

### Interface & Graphics

| Property | Values | Default | Description |
|----------|--------|---------|-------------|
| `&lt;theme&gt;` | `FlatLaf Dark`, `FlatLaf Light`, `FlatLaf IntelliJ`, `FlatLaf Darcula`, `FlatLaf macOS Dark`, `FlatLaf macOS Light`, `System Look and Feel` | `FlatLaf macOS Light` | The Swing look-and-feel stylesheet theme. |
| `&lt;graphicsFilter&gt;` | `Nearest Neighbor`, `Bilinear`, `Bicubic`, `Scale2x`, `CRT Scanlines`, `LCD Grid` | `Nearest Neighbor` | The scaling filter and shader effect used on the Canvas. |
| `&lt;fullscreen&gt;` | `true`, `false` | `false` | Start the emulator in fullscreen mode. |
| `&lt;showMouseCoordinates&gt;` | `true`, `false` | `false` | Show pointer coordinates overlay on the display. |
| `&lt;scaledDisplayZoom&gt;` | `2`, `3`, `4`, `-1` | `-1` | Set integer zoom scaling factor (`-1` to disable). |

### Performance & Limits

| Property | Values | Default | Description |
|----------|--------|---------|-------------|
| `&lt;memoryLimit&gt;` | `0`, `32`, `64`, `128`, `256`, `512` | `64` | Memory allocation limit in MB (0 = Unlimited). |
| `&lt;maxFps&gt;` | `-1`, `60`, `30`, `20`, `15` | `-1` | Frame rate limiter (-1 = Unlimited). |
| `&lt;speedMultiplier&gt;` | `1.0`, `1.5`, `2.0`, `4.0`, `8.0`, `0.5` | `1.0` | Simulation speed scaling factor. |
| `&lt;sleepMode&gt;` | `true`, `false` | `false` | Enable thread sleeping to reduce CPU usage. |
| `&lt;perfHudEnabled&gt;` | `true`, `false` | `false` | Display performance diagnostic HUD overlay. |

### Network & Proxy

| Property | Values | Default | Description |
|----------|--------|---------|-------------|
| `&lt;networkAccess&gt;` | `true`, `false` | `true` | Globally toggle MIDlet Internet access. |
| `&lt;networkOverlayEnabled&gt;` | `true`, `false` | `false` | Display network latency and activity overlay. |
| `&lt;proxyEnabled&gt;` | `true`, `false` | `false` | Enable proxy forwarding for outbound connections. |
| `&lt;proxyType&gt;` | `HTTP`, `SOCKS` | `HTTP` | Protocol of the proxy server. |
| `&lt;proxyHost&gt;` | String | (empty) | Host address of the proxy server. |
| `&lt;proxyPort&gt;` | Integer | `8080` | Port of the proxy server. |
| `&lt;proxyAuthEnabled&gt;` | `true`, `false` | `false` | Enable authentication credentials for the proxy. |

<Callout type="warning">
Do not modify the configuration file while the emulator is running, as it will overwrite changes upon saving on exit.
</Callout>
