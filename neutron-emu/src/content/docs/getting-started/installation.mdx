## Download

Neutron is distributed as self-contained Java executables (JARs). You can download pre-built release binaries directly from our [Download Page](/download) or the official [GitHub Releases](https://github.com/nsomatrix/neutron/releases).

### Available Packages

Neutron is distributed in two release packages to fit different development and emulation needs:

| Package | Artifact | Typical Size | Description |
|---------|----------|--------------|-------------|
| **Neutron Express (Full GUI)** | `neutron-1.4.0.jar` | ~2.2 MB | Complete desktop edition with FlatLaf modern UI themes, menus, diagnostics, library explorer, and graphical controls. |
| **Neutron Core (Optimized)** | `neutron-core-1.4.0.jar` | ~840 KB | Minimal distribution with an embedded LZMA2/XZ payload loader, fast startup, and ultra-compact disk footprint. |

Both editions include identical J2ME subsystem support: MIDP 2.0, CLDC 1.1, MMAPI audio (WAV, MIDI, tone), MascotCapsule Micro3D v3, JSR-184 (M3G), Nokia UI DirectGraphics, JSR-75 (FileConnection), JSR-82, JSR-120 (WMA SMS), and OEM APIs (Sony Ericsson, Motorola, Samsung).

## Prerequisites

Before running Neutron, ensure you have a Java Runtime Environment (JRE) or Java Development Kit (JDK) installed:

- **Minimum:** Java 8 (JRE / OpenJDK 1.8)
- **Recommended:** Java 17+ or Java 21+ LTS ([Eclipse Temurin](https://adoptium.net/))

Verify your Java version in your terminal:

```bash
java -version
```

## Launch Instructions

### Universal Desktop Execution

Because Neutron is packaged as executable JAR files, you can run it on Windows, macOS, or Linux using Java:

```bash
# Launch Neutron Express (Desktop GUI)
java -jar neutron-1.4.0.jar

# Launch Neutron Core (Minimal Footprint)
java -jar neutron-core-1.4.0.jar
```

You can also pass a game JAR file or JAD descriptor directly to start running immediately:

```bash
java -jar neutron-1.4.0.jar path/to/game.jar
```

### Windows

1. Download `neutron-1.4.0.jar` (or `neutron-core-1.4.0.jar`).
2. Double-click the `.jar` file to launch the emulator interface directly (if `.jar` file associations are set to Java).
3. Or open Command Prompt / PowerShell and run:
   ```cmd
   java -jar neutron-1.4.0.jar
   ```

### macOS

1. Download `neutron-1.4.0.jar` to your machine.
2. Open Terminal, navigate to your download directory, and execute:
   ```bash
   java -jar neutron-1.4.0.jar
   ```
3. To open a game immediately:
   ```bash
   java -jar neutron-1.4.0.jar /path/to/game.jar
   ```

<Callout type="tip">
On macOS, Neutron automatically adapts native screen menubars and system appearance dark/light modes.
</Callout>

### Linux

1. Ensure standard X11/Wayland display server and ALSA sound libraries are present:
   ```bash
   # Ubuntu / Debian
   sudo apt install openjdk-17-jre libasound2

   # Fedora
   sudo dnf install java-17-openjdk alsa-lib
   ```
2. Run Neutron:
   ```bash
   java -jar neutron-1.4.0.jar
   ```

## Convenient Terminal Alias

For fast access from anywhere in your shell, add an alias to your shell profile (`~/.bashrc`, `~/.zshrc`, or PowerShell profile):

```bash
# Bash / Zsh
alias neutron='java -jar /path/to/neutron-1.4.0.jar'
```

Once set, launch any game with:

```bash
neutron mygame.jar
```
