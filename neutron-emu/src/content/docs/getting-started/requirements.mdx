## System Requirements

### Minimum Requirements

| Component | Requirement |
|-----------|------------|
| Operating System | Windows 10, macOS 11, Ubuntu 20.04 |
| Processor | Any x86_64 or ARM64 CPU |
| Memory | 256 MB RAM |
| Disk Space | 50 MB |
| Java | JRE / JDK 8+ |

### Recommended

| Component | Recommendation |
|-----------|---------------|
| Operating System | Latest stable release |
| Processor | Multi-core CPU |
| Memory | 512 MB RAM |
| Disk Space | 100 MB (including ROMs) |
| Java | JRE / JDK 8 or later (JDK 17+ recommended) |

## Java Installation

Neutron requires a Java Runtime Environment (JRE) or Java Development Kit (JDK) version 8 or later. We recommend using one of these distributions:

- [Eclipse Temurin](https://adoptium.net/) (recommended)
- [Oracle JDK](https://www.oracle.com/java/)
- [Amazon Corretto](https://aws.amazon.com/corretto/)

### Verify Java Installation

```bash
java -version
# openjdk version "1.8.0_492"
```

<Callout type="info">
A standard Java Runtime Environment (JRE) is sufficient to run Neutron. You do not need to install the full Java Development Kit (JDK).
</Callout>

## Platform-Specific Notes

### Windows

- Windows Defender may flag the first launch — this is a false positive
- For best performance, disable Windows Game Mode when using the emulator

### macOS

- On Apple Silicon (M1/M2/M3), Neutron runs natively via Rosetta 2 or the ARM build
- Grant accessibility permissions if prompted for input handling

### Linux

- X11 and Wayland are both supported
- Install `libasound2` for audio support on Debian-based systems:

```bash
sudo apt install libasound2-dev
```
