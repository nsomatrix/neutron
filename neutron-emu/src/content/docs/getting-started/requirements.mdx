## System Requirements

Because Neutron executes directly on the host Java Virtual Machine, it enjoys native execution efficiency and minimal hardware overhead.

### Minimum System Specifications

| Component | Minimum Requirement |
|-----------|---------------------|
| **Operating System** | Windows 10, macOS 11+, or Linux (glibc 2.27+) |
| **Processor** | Any x86_64 (Intel / AMD) or ARM64 (Apple Silicon / Raspberry Pi) CPU |
| **Memory (RAM)** | 256 MB free memory |
| **Storage** | 50 MB disk space |
| **Java Runtime** | Java 8 (JRE / JDK 1.8) |

### Recommended Specifications

| Component | Recommended Specification |
|-----------|---------------------------|
| **Operating System** | Windows 11, macOS Sonoma / Sequoia, or modern Linux |
| **Processor** | Multi-core 2.0 GHz+ CPU |
| **Memory (RAM)** | 1 GB free memory |
| **Storage** | 200 MB disk space (for emulator, save states, and game ROMs) |
| **Java Runtime** | **JDK 17 LTS or JDK 21 LTS** ([Eclipse Temurin](https://adoptium.net/)) |

## Java Runtime Setup

Neutron requires a Java Runtime Environment (JRE) or Java Development Kit (JDK) version 8 or higher. For best performance, high-DPI scaling, and modern garbage collection, we strongly recommend **Java 17 or 21 LTS**.

### Recommended Distributions

- **[Eclipse Temurin (Adoptium)](https://adoptium.net/)** — Officially recommended, tested, open-source build of OpenJDK.
- **[Amazon Corretto](https://aws.amazon.com/corretto/)** — Production-ready multi-platform OpenJDK distribution.
- **[Oracle Java](https://www.oracle.com/java/)** — Standard Oracle JDK release.

### Check Your Java Version

Open a terminal or command prompt and run:

```bash
java -version
```

Example valid output:
```text
openjdk version "17.0.10" 2024-01-16
OpenJDK Runtime Environment Temurin-17.0.10+7 (build 17.0.10+7)
OpenJDK 64-Bit Server VM Temurin-17.0.10+7 (build 17.0.10+7, mixed mode, sharing)
```

<Callout type="info">
To run the pre-built `.jar` releases, a lightweight **Java Runtime Environment (JRE)** is completely sufficient. You only need the full **Java Development Kit (JDK)** if you intend to [build Neutron from source](/docs/development/building-from-source).
</Callout>

## Operating System Notes

### Linux Audio Libraries
On Linux distributions, Java utilizes ALSA for digital audio output. Make sure the ALSA runtime package is installed:

- **Ubuntu / Debian:** `sudo apt install libasound2`
- **Fedora / RHEL:** `sudo dnf install alsa-lib`
- **Arch Linux:** `sudo pacman -S alsa-lib`

### High-DPI Displays (4K / Retina)
Neutron uses the Marlin rendering engine and modern FlatLaf vector styling. High-DPI display scaling factors (125%, 150%, 200%) on Windows, macOS Retina, and Linux Wayland/X11 are supported automatically.
