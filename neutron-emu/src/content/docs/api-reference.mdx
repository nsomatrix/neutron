## Supported APIs

Neutron implements the following Java ME specifications:

## CLDC 1.1

### Core Packages

| Package | Description |
|---------|-------------|
| `java.lang` | Core language classes (Object, String, Thread, Math) |
| `java.lang.ref` | Weak references |
| `java.util` | Collections (Vector, Hashtable, Stack) |
| `java.io` | I/O streams and readers |

### Connection Framework

| Class | Description |
|-------|-------------|
| `Connector` | Factory for creating connections |
| `Connection` | Base connection interface |
| `InputConnection` | Connection with input stream |
| `OutputConnection` | Connection with output stream |
| `StreamConnection` | Bidirectional stream connection |

## MIDP 2.0

### LCDUI

| Class | Description |
|-------|-------------|
| `Display` | Display manager |
| `Displayable` | Base class for screens |
| `Canvas` | Low-level drawing surface |
| `Form` | High-level form container |
| `List` | Selection list |
| `TextBox` | Text input |
| `Alert` | Notification dialog |
| `Command` | Menu action |
| `Graphics` | 2D drawing context |
| `Image` | Image handling |
| `Font` | Text rendering |

### Game API

| Class | Description |
|-------|-------------|
| `GameCanvas` | Game-optimized canvas |
| `Sprite` | Animated sprite |
| `TiledLayer` | Tile-based background |
| `LayerManager` | Layer composition |

### RMS

| Class | Description |
|-------|-------------|
| `RecordStore` | Persistent data store |
| `RecordEnumeration` | Record iteration |
| `RecordFilter` | Record filtering |
| `RecordComparator` | Record sorting |

### Networking

| Interface | URL Scheme |
|-----------|-----------|
| `HttpConnection` | `http://` |
| `HttpsConnection` | `https://` |
| `SocketConnection` | `socket://` |
| `DatagramConnection` | `datagram://` |

### Media (MMAPI)

| Class | Description |
|-------|-------------|
| `Manager` | Media manager |
| `Player` | Media player |
| `VolumeControl` | Volume control |
| `StopTimeControl` | Playback timing |

<Callout type="info">
For the complete Java ME API documentation, refer to the [official MIDP 2.0 specification](https://docs.oracle.com/javame/config/cldc/ref-impl/midp2.0/jsr118/).
</Callout>
